# Clean-room rules

- Do not decompile, disassemble or copy code from Picasa or any Google software.
- Do not copy Picasa icons, images, sounds or the "Picasa" name/logo. Draw original icons (see `src/components/Icons.tsx`).
- Reading user data files Picasa left behind (e.g. `scanlist.txt`, `.picasa.ini`) for import/interoperability is allowed.
- Behaviour is matched by observation and documented in `docs/PICASA_SPEC.md`.
