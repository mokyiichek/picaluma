⚡

Instant search

Type and results appear as you go — file names, folders, captions, tags and cameras, across your whole library.

All your folders on one smooth, scrolling page, newest first — click a folder and glide straight to it.

One-click fixes

Install in a minute

The Mac version is signed and notarized by Apple. On Windows, SmartScreen may ask you to confirm once.

Windows

  1. Run Picaluma_…_x64-setup.exe. It installs just for you — no admin rights needed.
  2. If you see “Windows protected your PC”, click More info → Run anyway.
  3. Open Picaluma and choose the folders to watch. Coming from Picasa? Import your old folder list in one click.

Mac

  1. Open Picaluma_…_universal.dmg and drag Picaluma into Applications, then open it. It's notarized by Apple, so it opens like any other Mac app.
  2. Prefer Terminal? This line downloads, installs and opens the latest version: 
    curl -fsSL https://ahmok.com/picaluma/install.sh | bash
  3. Choose Watch my Pictures folder or any folders you like. HEIC photos from your iPhone work too.
